# TaskFlow - Task Manager

TaskFlow is a simple task management web application built using HTML, CSS, and JavaScript.

## Features

* Add a task with a non-empty title.
* Mark a task as complete or pending.
* Delete a task from the list.

## Technologies Used

* HTML
* CSS
* JavaScript
* Git and GitHub

## How to Run

1. Clone or download the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Testing

* Verify that an empty task cannot be added.
* Add a task and confirm it appears in the list.
* Toggle its status between Complete and Pending.
* Delete a task and confirm it disappears.
